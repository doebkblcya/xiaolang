# 插件与管理面板开发

更新：2026-10-24。当前公开运行接口为 API v1，代码见 [plugin-api.ts](../../src/plugin-api.ts)、[contracts.ts](../../src/contracts.ts)、[panel.ts](../../src/panel.ts)和[面板注册器](../../examples/plugins/panel/registry.mjs)。

## 插件职责

内置／外挂是交付位置，不是启停权限等级。宿主提供插件生命周期、配置、存储、调度、工具、用量、日志等服务；QQ、模型、触发、记忆、学习和具体工具实现位于外挂。使用 Cordis 服务依赖连接，依赖缺失则等待；停用释放监听、定时器与任务，不删除配置及数据。

外挂入口和 `xiaolang.plugin.json` 侧车声明配置、依赖、面板及可选清理模块。宿主能在能力停用时展示声明并执行数据清理，不为了显示面板而启动插件。公共 `_runtime.mjs` 由宿主生成，用于复用契约和类身份；不要在外挂复制私有宿主服务，也不把密钥写进该文件。

## 三个可选界面位置

| 位置 | 定义 | 使用方式 |
| --- | --- | --- |
| 插件详情配置 | configSchema；需要自定义时加 panel.detail | 简单配置直接由通用表单生成；复杂结构可自定义编辑器。 |
| 主页模块 | panel.home 与 xiaolangPanelHome | 简短运行信息和可选跳转；提供者自己读取所属服务。 |
| 完整侧栏页面 | panel.pages | 插件认为需要时主动声明，不要求每个插件都有。 |

固定导航只保留主页和插件目录；独立页面按运行时插件顺序及各自声明顺序依次展示，不按查看／配置分组，不置顶。主页模块同样沿插件与声明顺序，不新增权重、常用排序或拖动持久化规则。

详情区和完整页可以挂同一编辑器，它们读写同一个配置版本，**不是保存两份互不相关的配置**。注册完整页面也不代表面板取得跨插件内部表的访问权。

## 声明示例

外挂在侧车中写 `panel`，运行模块可导出同内容的 `xiaolangPanel`。下面以一个独立插件为例：

```json
{
  "id": "example",
  "apiVersion": 1,
  "dependencies": ["xiaolangHost"],
  "configSchema": {
    "type": "object",
    "additionalProperties": false,
    "properties": { "greeting": { "type": "string", "title": "问候语", "maxLength": 100 } }
  },
  "panel": {
    "detail": { "entry": "./panel/config.js" },
    "pages": [{ "id": "settings", "title": "示例设置", "entry": "./panel/config.js" }],
    "home": [{ "id": "status", "title": "示例状态", "action": "settings" }]
  }
}
```

每份 content 在 `view` 和 `entry` 中二选一。`view` 对应面板已支持的视图名，新增真正独立的编辑器用 `entry`。entry 限制在插件内 `./panel/` 的 `.js`，资源按真实路径校验，不能借软链接越出目录。完整页最多 12 个，主页模块最多 8 个；各自 id 不重复。

主页模块 action 可省略；`detail` 表示插件详情，其他值必须是本插件已注册的 page id。只提供短文本、可选说明和统一 tone：

```js
export const xiaolangPanelHome = (ctx, id) => ({
  value: '运行中', detail: '简短状态', tone: 'good'
});
```

value 最多 120 字符，detail 最多 160；tone 支持 good、neutral、waiting、bad。每个 reader 最多等待 1 秒，异常只影响自身；停用不调用 reader，显示停用／依赖等待等状态，插件缺失不展示模块。主页不检查 QQ 或 DeepSeek 的具体名称和私有字段。

## 自定义编辑器

编辑器导出 `mount({ root, plugin, api, signal })`，用 DOM 生成内容，通过 `api.get` 和 `api.request` 读取／保存插件配置。完整可运行示例见 [hello/panel/config.js](../../examples/plugins/hello/panel/config.js)及[侧车声明](../../examples/plugins/hello/xiaolang.plugin.json)。

```js
export async function mount({ root, plugin, api, signal }) {
  const path = `/api/plugins/${encodeURIComponent(plugin.id)}`;
  const detail = await api.get(path);
  // 保存时带最新 revision；已有配置的其他字段应一并保留。
  // await api.request(path, { revision: detail.revision, config: updatedConfig });
  // 事件监听使用 { signal }，异步任务应支持卸载取消。
}
```

使用面板提供的接口封装，写入仍校验 Key 会话、同源写入令牌及配置 revision；不嵌入密钥，不另开无鉴权写接口。保存产生待应用配置，沿用原应用重启和失败回退流程。页面草稿与其他页面冲突应明确显示，不静默覆盖。

## 当前页面由谁提供

| 页面／模块 | 提供者 |
| --- | --- |
| 主页框架、插画、宿主机和进程只读指标 | panel 外挂；生命周期来自宿主 xiaolangRuntime。 |
| 插件目录和通用详情 | panel 根据运行时目录及配置注册生成。 |
| QQ 连接模块、QQ 接入页 | xiaolang-adapter。 |
| 回复模型模块、回复模型页及可选余额接口 | xiaolang-deepseek。 |
| 触发规则 | xiaolang-trigger。 |
| 聊天与记忆、图片描述／召回／摘要能力 | xiaolang-memory。 |
| 人设与学习、手动主人格编辑 | xiaolang-persona。 |
| 定时提醒 | xiaolang-reminders。 |
| 过程日志 | xiaolang-logging 注册页面，统一日志服务提供数据。 |
| 聊天记录 | xiaolang-store 注册，记忆、日志和适配器可选补充详情。 |
| 模型用量 | xiaolang-usage 注册，模型服务可选提供余额，不新增强依赖。 |
| 工具与行动 | xiaolang-tools 注册，实际工具／来源由各工具插件提供。 |

面板负责展示和操作编排，不承接其他插件的业务解析。可选服务缺失时显示不可用，不能令整个主页或其他配置页面报错。

## 工具展示与执行记录

工具注册时提供 `title`、`summary`、`owner`／`source` 等展示元数据；名称、完整 description、参数 Schema、access、effect 和 timeoutMs 仍按统一工具契约校验。来源通过 `ctx.tools.registerSource` 注册 plugin、title 和可选 status；卸载时执行其返回的释放函数。来源状态读取也有 1 秒超时，MCP／Skills 自己组织连接或目录状态，面板不读取其私有配置。

调用管理员判断使用适配器传入的真实用户 ID，不能信任模型参数中的身份。普通只读工具可公开；有写副作用默认要求管理员。Schema 兼容策略由提供者显式声明，不能因某个 MCP 需要兼容而放松全部工具校验。

执行记录读取统一日志的工具成功／失败／结果未知事件，不另建面板执行表。结果未知的工具不能假设未执行或自动重复。不要为了展示工具目录而调用工具、模型或远程脚本。

## 视觉与资源约定

奶白背景、巧克力棕文字、焦糖点缀；统一四角圆角矩形、表单与开关，避免一页一套组件。长文本、JSON、数组占完整行；布尔项使用紧凑开关，不继承普通输入框的大尺寸。说明只保留有助于理解字段和操作结果的内容。

[面板资源目录](../../examples/plugins/panel/assets)中，halfbody WebP 用于登录，window WebP 用于主页；fullbody 是备用设定素材。PNG 是原始生成源，prompt.txt 记录生成依据，保留用于后续编辑，不当作废弃截图删除。运行页面使用 WebP，人物耳朵与主体不能被容器生硬裁断。
