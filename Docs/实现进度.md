## 实测回复要多久

下面是关闭聊天思考时的旧基线；开启 high 后需重新观察，不沿用为当前耗时承诺。两轮真实群聊中，直接叫“小狼”约 2.3 秒首段发送确认；不带触发词接着聊约 3.3 秒首段、4.4 秒全部发送完成。

| 环节 | 直接叫“小狼” | 不带触发词接着聊 |
| --- | --- | --- |
| 收集新消息 | 无 | 0.25 秒 |
| 判断是否接话 | 无 | 0.80 秒 |
| 记忆检索与历史准备 | 约 0.21 秒 | 约 0.19 秒 |
| 请求回复模型至第一句可发送 | 0.67 秒 | 0.79 秒 |
| 第一段发送至 QQ 确认 | 1.42 秒 | 1.20 秒 |
| 第二段发送至 QQ 确认 | 无 | 1.13 秒 |

这两轮中，分段发送等待占时最多，每段约 1.1～1.4 秒；它包含网络往返、QQ 接口响应和本地回执记录，不能全部算成 QQ 服务器处理时间。排队和 Prompt 准备等其余步骤合计约 0.05 秒。

计时从 NAS 收到消息开始，到 QQ 接口确认发送为止，不等于手机端实际显示时间。流式“模型耗时”包含部分分段发送等待，不能与发送耗时重复相加。两轮均未调用搜索、图片或 MCP，也未接近 10 万 Token 上限，不代表平均值或所有场景的速度。当时旁观期的 10 秒是有意等待积累聊天（本次已改为 60 秒或 20 条）；这两轮走的是直接触发／活跃接续，不含该等待。
